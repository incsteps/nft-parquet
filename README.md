# `nft-parquet` Plugin

This plugin extends **`nf-test`** (Nextflow testing framework) with a custom **Parquet file extension**, 
allowing you to easily validate the content and structure of [Apache Parquet](https://parquet.apache.org/) files generated by your Nextflow pipelines.

---

## Features

- **Simple & Expressive Syntax:** Integrates seamlessly into `nf-test` assertions, leveraging Groovy's `with` construct.
- **Structural Inspection:** Validate total row counts, column counts, and column names.
- **Content Validation:**
    - Access full record sets in memory using `rows`.
    - Fetch specific rows on demand with `rowIndex(n)` to minimize memory footprint on large datasets.
- **Schema Validation:** Verify columns and their expected Java/Groovy data types.

## Usage Examples

### 1. Structural Validation
Verify basic metadata like row count, column count, and column names.

```groovy
test("Should validate parquet structure") {
    then {
        def outfile = workflow.out.get(0)[0]

        with(path(outfile).parquet) {
            assert rowCount == 10_000
            assert columnCount == 5
            assert columnNames == ["id", "name", "sizell", "value", "percentile"]
        }
    }
}
```

### 2. Content Validation (rows vs rowIndex)
Depending on file size, choose between full in-memory loading or direct index access.

```groovy
test("Should validate parquet content") {
  then {
    def outfile = workflow.out.get(0)[0]

    // Option A: Full rows array (use only if file is small enough for memory)
    assert path(outfile).parquet.rows[0] == [1, 'the 1 record', 1, 1.0, 1.0]

    // Option B: Direct index lookup (recommended for large files to avoid OOM)
    assert path(outfile).parquet.rowIndex(500) == [500, 'the 500 record', 500, 500.0, 500.0]
  }
}
```

### 3. Schema Validation
Verify column names and data types.

```groovy
test("Should validate parquet schema") {
  then {
    def outfile = workflow.out.get(0)[0]

    assert path(outfile).parquet.schema == [
            "id": Long,
            "name": String,
            "percentile": Double,
            "sizell": Long,
            "value": Double
    ]
  }
}
```
